# Tutorials

Step-by-step guides to installing and using Sklearn-Wrap in your project.

- [Getting Started](getting-started.md): Install Sklearn-Wrap and create your first wrapper, learning the basic pattern and gaining Scikit-Learn meta estimator compatibility in minutes.
- [Wrapping Functions](wrapping-functions.md): Wrap standalone functions into sklearn-compatible functors, learning the keyword-only convention, functor calls, and how to extend to a full estimator.
- [Examples](../examples/index.md): Interactive notebooks covering core features, from basic wrapping and parameter validation to GridSearchCV integration and YAML configuration.
